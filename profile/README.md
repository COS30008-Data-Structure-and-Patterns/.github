# COS30008 — Data Structures and Patterns

**Swinburne University of Technology | Semester 1, 2026**

## About the Unit

COS30008 explores the design, implementation, and application of data structures for algorithmic problem-solving. It focuses on choosing suitable data representations, evaluating time and space requirements, and recognising reusable software design patterns.

## Key Topics

- **C++ and object-oriented programming:** classes, inheritance, polymorphism, pointers, templates, and memory management.
- **Data structures:** dynamic arrays, linked lists, stacks, queues, hash tables, trees, and graphs.
- **Algorithms and analysis:** asymptotic complexity, performance analysis, greedy algorithms, backtracking, and divide and conquer.
- **Design patterns:** reusable approaches to software design, including iterator and visitor patterns.

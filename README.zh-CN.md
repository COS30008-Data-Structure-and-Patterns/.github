# COS30008 — 数据结构与设计模式

**斯威本科技大学（Swinburne University of Technology）| 2026 年第一学期**

## 课程简介

COS30008（Data Structures and Patterns）主要研究如何设计、实现和应用数据结构，以解决算法问题。课程重点包括选择合适的数据表示方式、分析时间与空间资源消耗，以及识别和运用可复用的软件设计模式。

## 核心学习内容

- **C++ 与面向对象编程：** 类、继承、多态、指针、模板及内存管理。
- **数据结构：** 动态数组、链表、栈、队列、哈希表、树与图。
- **算法与分析：** 渐近复杂度、性能分析、贪心算法、回溯法与分治法。
- **设计模式：** 可复用的软件设计方法，包括迭代器模式（Iterator）和访问者模式（Visitor）。
